# Новогодний корпоратив 2025 — коммерческое предложение (8 слайдов, 16:9)

**«Предварительный заказ новогоднего корпоратива. Ключевые преимущества»**
Premium-сегмент: Black Tie / Vogue / Met Gala. Никаких клипартов — только
глубокий цвет, золотые hairline-линии, матовые «стеклянные» плашки и воздух.

## Файлы

| Файл | Назначение |
|---|---|
| `preorder_new_year_corporate_2025.pptx` | **Готовая презентация** (скачать и открыть) |
| `preorder_new_year_corporate_2025.pdf` | **PDF-версия** (8 страниц, 16:9, 2880×1620) |
| `build_presentation.py` | Код генератора на python-pptx (весь дизайн в одном файле) |
| `make_logo.py` | Векторная реконструкция знака «Кьево» → PNG (белый / тёмный) |
| `assets/` | `logo_white.png` (вшит в дэк), `logo_dark.png` (для светлых носителей) |
| `render_preview.py` | Опциональный предпросмотр по `scene.json` (QA-инструмент) |
| `previews/` | PNG-превью всех 8 слайдов + contact sheet |

## Дайджест структуры

1. **Обложка** — логотип по центру сверху, H1, золотой подзаголовок «7 причин…», тег-плашка «Москва · Сезон 2024–2025».
2. **01 · Доступ к эксклюзиву** — «Лучшие площадки и даты» + карточка золотых дат и плашка «Прайм-тайм декабря гарантирован».
3. **02 · Финансовая оптимизация** — «Скидка 10% на любую площадку» + круглый бейдж «−10% НА АРЕНДУ».
4. **03 · Креатив и режиссура** — 3 авторские концепции (иммерсивное шоу / светский гала-ужин / индивидуальный кастом).
5. **04 · Безопасный старт** — «Предоплата 30%» + шкала доли «30% для старта».
6. **05 · Комфорт для бухгалтерии** — «Удобный график платежей» + таймлайн Транш 1 → Транш 2 → Финал.
7. **06 · Подарок №1** — онлайн-тимбилдинг в подарок, плашка «SPECIAL GIFT / 0 ₽».
8. **07 · Подарок №2 + CTA** — шоу-торт с логотипом компании, финальный блок «Забронируйте встречу…» с контактами.

## Дизайн-система (единая сетка)

**Палитра**
- Фон: Deep Midnight Blue `#0A0F1D` + вертикальный градиент глубины (`#111A30 → #080C16`)
- Акцент: Champagne Gold `#D4AF37`, текст-акцент `#E5C378`
- Текст: белый `#FFFFFF`, второстепенный `#A0AEC0`
- «Матовое стекло»: заливка белого 4–5% + рамка белого 10–16% / золотой 1px

**Типографика** (оба шрифта бесплатны — Google Fonts, кириллица включена)
- Заголовки, нумерация, бейджи: **Montserrat** (Bold, трекинг +300 у оверлеев)
- Основной текст: **Inter** (Regular, 12.5pt, межстрочный 1.42)

**Сетка**
- Поля 0.9" · левая колонна (контент) 6.9" · правая колонна (визуал) 4.28"
- Шапка: оверлей слева + слот логотипа справа + золотая линия на y=1.12"
- Подвал: линия, «0X / 08» слева, подпись бренда справа
- Фирменные элементы: полупрозрачная цифра преимущества (ghost number),
  золотой ромб-маркер, hairline-линии 0.75–1px

## Как заменить

- **Логотип** — знак «Кьево» уже вшит: на титульном — крупно по центру
  (0.95"), на слайдах 2–8 — в правом верхнем углу (0.4"). Источник —
  `assets/logo_white.png` (белый, прозрачный фон, квадрат), генерируется
  скриптом `make_logo.py`. Если нужен исходный файл именно вашего знака —
  просто замените `assets/logo_white.png` (720×720, белый, прозрачный фон)
  и пересоберите: `python build_presentation.py`.
- **Контакты (слайд 8)** — строки «ТЕЛЕФОН · ПОЧТА · TELEGRAM» в CTA-блоке.
- **Даты, проценты, имена** — в функциях `slide_02 … slide_08` в
  `build_presentation.py` (каждый слайд — отдельная функция, комментарии на месте).

## Пересборка

```bash
pip install python-pptx
python build_presentation.py
# -> preorder_new_year_corporate_2025.pptx + scene.json
```

**PDF** собирается рендером той же геометрии (шрифты Montserrat/Inter, 2×):
```bash
pip install pillow fonttools
python render_preview.py scene.json /tmp/hi --scale 216 \
    --pdf preorder_new_year_corporate_2025.pdf
```
PDF — растровый (по 2880×1620 на страницу); если нужен редактируемый
векторный PDF со слоем текста, используйте «Экспорт в PDF» из PowerPoint.

Шрифты **Montserrat** и **Inter** должны быть установлены на машине,
где открывается файл (иначе PowerPoint подставит системный аналог).
